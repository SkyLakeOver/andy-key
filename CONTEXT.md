# Контекст проекта: Inventory System (Go + SQLite)

## 1. Цель
Создание локальной, portable-системы учёта IT-имущества для распределённой организации.
- **Стек:** Go, SQLite (pure-Go driver), HTMX (UI), excelize (XLSX export).
- **Деплой:** Изначально локальный (.exe/.bin), с возможностью миграции в Docker/K8s.
- **Хранение:** Один бинарный файл + один файл БД (`inventory.db`).

## 2. Архитектура данных (Иерархия)
Система должна учитывать юридическое разделение организаций и географическое распределение.

### Сущности:
1. **Organization** (Юридическое лицо):
   - `is_branch`: false (головная) / true (дочерняя/филиал).
   - Примеры: "Главное учреждение", "Филиал Север".
2. **Location** (Здание/Адрес):
   - Принадлежит одной Organization.
   - Примеры: "ул. Иванова 20", "ул. Ленина 11".
3. **Department** (Отдел/Подразделение):
   - Принадлежит одной Organization.
   - Может работать в нескольких Location (многие-ко-многим).
4. **Room** (Кабинет):
   - Находится в одном Location.
   - Принадлежит одному Department.
5. **Employee** (Сотрудник):
   - Принадлежит одной Organization и одному Department.
   - Работает в одном Room (физическое место).
   - **Важно:** Сотрудник может быть *прикомандирован* (работать в здании другой организации), но юридически оставаться в своей.
6. **Item** (Имущество: ПК, МФУ):
   - Принадлежит одной Organization (баланс).
   - Закреплено за Employee (может быть NULL).
   - Физически находится в Room.

## 3. Требования к MVP
1. **Просмотр:**
   - Список Организаций.
   - Внутри организации: Список Зданий → Кабинетов.
   - Внутри кабинета: Сотрудники и их оборудование.
2. **Экспорт:**
   - Генерация XLSX (Excel) отчётов по зданию/кабинету.
3. **UI:**
   - Веб-интерфейс на базе HTMX (серверный рендеринг HTML).
   - Адаптивный, минималистичный.

## 4. Технический стек
- **Язык:** Go 1.23+
- **БД:** `modernc.org/sqlite` (CGO_ENABLED=0 для портативности).
- **Web:** `net/http` + `html/template` + `htmx`.
- **Excel:** `github.com/xuri/excelize/v2`.
- **Структура:**
  - `cmd/main.go`: Точка входа.
  - `internal/db/`: Подключение к БД, миграции.
  - `internal/models/`: Структуры данных.
  - `internal/handlers/`: HTTP обработчики.
  - `web/`: Шаблоны и статика (embed).

## 5. Текущий статус
- Проект инициализирован в `J:\proj_inventory`.
- Требуется реализация схемы БД и первых handlers для отображения списка организаций.
